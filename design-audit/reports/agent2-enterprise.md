# Agent 2 – Enterprise Agency Teardowns (Group A, enterprise)

Client: eComet (teamecomet.com). Reference sites: stackworx.co, arhamsoft.com, arbisoft.com, appinventiv.com.
Capture tool: playwright-core 1.63 + headless Microsoft Edge 154, 1440x900 desktop and 390x844 iPhone UA, captured 2026-09-29 between 10:54 and 12:10 local time. All evidence paths below are relative to `scratchpad/evidence/`. Every finding is tagged CONFIRMED (seen in the named screenshot, data.json, extra-data.json or WebFetch text extraction) or UNVERIFIED (inferred).

Evidence-quality note: the first batch ran while five other headless browsers were active on the same machine (three agents' batches). Desktop timing values captured in that window (Arbisoft, Appinventiv desktop pass) are inflated; the mobile passes and the StackWorx/ArhamSoft re-runs happened under lighter load and are more representative. Absolute figures are quoted as measured; use them for relative comparison only.

Additional tooling written for this teardown (in `scratchpad/harness/`): `summarize-a2.js` (compact data.json summary, output saved as `<slug>/summary.txt`), `crop-a2.js` (pure-JS PNG cropper used to produce `crop-*.png` views of full-page screenshots where the harness section clips were unreliable), `extra-a2.js` (DevTools-style follow-up: header computed style at top vs scrolled, mega-menu hover, mobile drawer, fixed/sticky elements, image alt inventory; output `<slug>/extra-data.json` and `extra-*.png`).

### 1.8 Ideas to borrow / avoid
Borrow:
1. **Outcome-first work cards** (tag → one bold metric sentence → scope line → tech tags). Works because a buyer reads a number before a brand name. Maps to eComet's home "Projects" grid and each project page header.
2. **Sticky stacking process cards** with abstract UI illustrations (real CSS `position: sticky`, no library). Cheap, robust, feels premium. Maps to eComet "How we work".
3. **Dark band with brand-colour radial glow + fine grid** for testimonials/team, with a coverflow carousel whose active card gets a 1px brand border. Maps directly to eComet's black + cyan→magenta gradient: use the gradient as the glow and the active-card border.
4. **Verified-platform badge on testimonials** ("Verified on Upwork"). Maps to eComet Testimonials page if their reviews come from Upwork/Clutch.
5. **Monospace eyebrow labels + tag pills as a system** for categories (services, problems, offices). Maps to eComet section labels.
Avoid:
- Shipping placeholder copy ("Give visitors one clear final action") and a permanently spinning image placeholder; localhost canonical/sitemap. Reason: these are exactly the credibility leaks a redesign must not introduce.
- Multi-megabyte SVG mockups (1.3 MB each) – export device mockups as WebP/AVIF.
